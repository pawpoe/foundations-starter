# CSC110 Final Activities | Foundations Path | Homework and In-Class Avctivity

## Project Overview

This project will consist of two learning activities that have been designed to help students practice basic Python programming concepts. The homework assignment will focus on using functions to calculate a restaurant bill, while the in-class activity will focus on predicting the output of Python for loops.

## Artifact 1: Homework Assignment - Restaurant Bill Calculator

The student's overall task for the homework will be to create a program that calculates a subtotal, tip, and final amount of a restaurant bill using functions.

### Learning Outcomes
1. Understand how to create and define functions in Python.
2. Understand how to use parameters and arguments.
3.  Learn how to return values from functions.
4.  Learn how to apply mathematical calculations within functions.
5.  Understand how to call multiple functions to complete a program.
 
### Misconceptions Addressed
- Confusing parameters and arguments
- Not understanding how functions return values
- Defining a function automatically runs it

## Artifact 2: In-Class Activity – Predicting Python For Loops

The in-class activity helps students understand Python for loops by having them predict what a program will display before running the code. Students will also modify loops and observe how changing the range affects the output.

### Learning Outcomes
- Understand how Python for loops work.
- Understand how the `range()` function works.
- Predict what a loop will print before running it.
- Understand how changing the range affects the number of repetitions.

### Misconceptions Addressed
- Thinking that `range(5)` includes the number 5.
- Not understanding how many times a loop repeats.
- Confusing the loop variable with the output.
- Not understanding how changing the range changes the output.

### Materials
- Computer or laptop
- Slides explaining Python for loops and the `range()` function
- Loop prediction worksheet
- Pen or pencil and paper

## How to Run the Code

1. Download or clone this GitHub repository.
2. Open the Python files using Python.
3. Open `restaurant_bill_starter.py` to work on the homework assignment.
4. Run the Python program to test the completed functions.
5. For the in-class activity, open the loop prediction worksheet and run the example loops in Python.
